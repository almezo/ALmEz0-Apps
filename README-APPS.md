# 📱💻 دليل تشغيل وبناء تطبيقات سيرفرات الميزو (ALmEz0)
### (Android APK + iPhone iOS + Windows EXE)

تم تحويل موقع **سيرفرات الميزو** بنجاح إلى تطبيقات احترافية تعمل على كافة المنصات!
فيما يلي الدليل الشامل لكيفية تشغيل واستخراج التطبيقات لكل جهاز:

---

## 1. تطبيق كمبيوتر ويندوز (Windows EXE) 💻

### الملفات الجاهزة:
ستجد ملفات التطبيق داخل مجلد `dist-electron/`:
1. **النسخة المحمولة (Portable EXE)**:
   - اسم الملف: `AlMeZ0-Servers-Portable.exe`
   - **طريقة التشغيل**: لا تحتاج تثبيت! انقر عليه نقرتين فقط وسيعمل التطبيق مباشرة كنافذة مستقلة وسريعة مع كامل مزايا وأقسام الموقع.
2. **برنامج التثبيت الرسمي (Setup Installer)**:
   - اسم الملف: `سيرفرات الميزو Setup 1.0.0.exe`
   - يقوم بتثبيت التطبيق على جهاز الكمبيوتر مع وضع اختصار على سطح المكتب وقائمة ابدأ وتعيين الأيقونة الرسمية.

### كيف تعيد بناء ملف الـ EXE في أي وقت مستقبلاً؟
- ببساطة اضغط نقرتين على الملف السريع: `build-windows-exe.bat`
- أو نفّذ الأمر في الطرفية:
  ```bash
  npm run electron:build
  ```

---

## 2. تطبيق أندرويد (Android APK) 🤖

تم إنشاء مشروع أندرويد أصلي متكامل عبر **Capacitor** داخل مجلد `android/` مع دمج الأيقونات وشاشات البداية وصلاحيات بث الـ IPTV.

### طريقتان للحصول على ملف الـ APK:

#### الطريقة الأولى (الأسهل والمجانية - عبر البناء السحابي GitHub Actions):
1. ارفع مجلد الموقع إلى مستودع GitHub خاص بك.
2. ستجد داخل المشروع ملف أتمتة جاهزاً قمنا بإنشائه لك:
   `.github/workflows/build-apps.yml`
3. بمجرد الرفع، ستقوم خوادم GitHub بتجميع وبناء ملف الـ APK تلقائياً في السحابة.
4. اذهب إلى تبويب **Actions** في صفحتك على GitHub وحمّل ملف `AlMeZ0-Android-APK` مباشرة إلى هاتفك وثبته!

#### الطريقة الثانية (البناء المحلي عبر أندرويد ستوديو):
1. افتح مشروع الأندرويد في برنامج Android Studio عبر الأمر:
   ```bash
   npm run cap:android
   ```
2. من القائمة العلوية اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. ستجد ملف الـ APK الناتج في المسار:
   `android/app/build/outputs/apk/debug/app-debug.apk`

## 3. تطبيق آيفون (iPhone iOS) 🍏

تم إنشاء مشروع iOS أصلي بالكامل داخل مجلد `ios/` يحتوي على `App.xcworkspace`.

### خيارات تشغيل التطبيق على أجهزة الآيفون:

#### الخيار الأول (فوري وبدون الحاجة لجهاز ماك - تثبيت PWA):
1. افتح رابط الموقع في متصفح **Safari** على جهاز الآيفون.
2. اضغط على زر المشاركة في أسفل الشاشة (أيقونة المربع وسهم لأعلى).
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ثم اضغط "إضافة".
4. سيظهر تطبيق **سيرفرات الميزو** فوراً على شاشة تطبيقات الآيفون بأيقونته الرسمية وسيعمل بدون شريط المتصفح وبشاشة كاملة ودعم النوتش والجزيرة التفاعلية.

#### الخيار الثاني (مشروع Xcode الأصلي للمطورين):
- إذا كنت تمتلك جهاز Mac أو حساب مطور Apple:
  1. افتح ملف `ios/App/App.xcworkspace` في برنامج **Xcode**.
  2. وصل جهاز الآيفون أو اختر المحاكي (Simulator) واضغط على زر التشغيل (Run) أو قم بتصدير ملف `.ipa`.

#### الخيار الثالث (البناء السحابي عبر GitHub Actions):
- يقوم ملف الأتمتة المرفق في المشروع بتشغيل خوادم macOS سحابية لحزم وبناء مشروع الـ iOS تلقائياً عند كل تحديث.

---

## 4. ملفات السكربتات السريعة المضافة للمشروع:
- `build-windows-exe.bat`: لبناء ملف الـ EXE للكمبيوتر بضغطة زر واحدة.
- `build-android-apk.bat`: لمزامنة وبناء تطبيق الأندرويد بضغطة زر واحدة.
- `scripts/prepare-app.js`: سكربت ذكي يقوم بتجهيز ملفات الويب النظيفة في مجلد `www/`.
- `scripts/setup-icons.ps1`: سكربت توليد الأيقونات بكافة المقاسات الأصلية لأنظمة أندرويد و iOS.
- `app-bridge.js`: جسر الربط الذكي للتوافقية وزر الرجوع وفتح الروابط الخارجية.
